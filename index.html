REFERENCE PRONUNCIATION

Ave Maria

Á-ve Ma-rí-a, grá-ti-a plé-na, Dó-mi-nus té-cum.

Acute accents and bold type mark the stressed syllables. Long vowels are not scored by this exercise.

Bundled reference: “Ave Maria in Latin language,” spoken in ecclesiastical pronunciation by an Italian speaker. Public domain; details in the project README.

THIS DEVICE

Compatibility & privacy

Capabilities vary by browser, Android version, installed services, and language packs. Nothing here assumes every device is the same.

Browser & offline

If an install prompt is not shown, use the browser's menu and choose “Install app” or “Add to Home screen” where available.

System speech voices

“Local service” is the browser's report about the synthesizer; it does not certify Latin quality or guarantee every device's offline behavior. Remote voices are listed but never used by this app.

Reference audio remains the pronunciation standard.

    On-device speech recognition

    Recognition is never switched to a remote service. A language pack download, if offered by your browser, happens only after you choose to install it.

    Your learning data

    Progress is stored in this browser on this device. Export it for a backup or to move it to another browser.

    Why AI features are limited

    Android's Gemini Nano / AICore and ML Kit GenAI are native Android app APIs, not interfaces a GitHub Pages website can call. Chrome's built-in Gemini Nano Prompt API is not supported on Chrome for Android. Browser on-device speech recognition is used only if the browser explicitly exposes its local-processing API and Latin pack; otherwise use recording and self-assessment.

    Learning recommendations are deterministic and work offline. No cloud model, external script, analytics, or account is used.
